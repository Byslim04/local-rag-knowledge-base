# Local RAG Knowledge Base (LlamaIndex + Ollama + Phi-3)


A local search and question-answering system for your knowledge base (Retrieval-Augmented Generation). The project runs entirely on your computer, without sending data to the cloud, without paid API keys, and with guaranteed privacy.

## 🛠️ Tech Stack

* RAG Orchestration: LlamaIndex (https://www.llamaindex.ai/).
* Local Language Model (LLM): Ollama (https://ollama.com/) (phi3).
* Vector Embeddings: HuggingFace (BAAI/bge-small-en-v1.5).
* Runtime Environment: Python 3.8+ (Windows / Linux / macOS).

## 📂 Project Structure

* rag_knowledge_base/ — Folder for your text documents.
* script.py — Main startup script.
* README.md — Project documentation.
